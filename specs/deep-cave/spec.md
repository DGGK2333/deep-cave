## 项目定位

单文件 HTML5 Canvas 2D 游戏（`deep-cave/index.html`，约 2832 行 / 142KB）。
箱庭式挖矿 Roguelite：地表补给与升级 → 下潜砸晶簇怪与怪物 → 沿绳返回结算 → 更深。

## 玩法决定 UI 规则

| 玩法事实 | 对 UI 的要求 |
|---|---|
| 绳索是命脉，随时可能绷紧被拽回 | **绳索状态必须是屏幕上最醒目的持续信息**，且要在暗色洞穴里也读得清 |
| 玩家在洞穴里持续移动+攻击，视线集中在角色 | HUD 只能占屏幕边缘；**中央区域永不常驻遮挡** |
| 一次下潜要背回一背包战利品 | 背包容量是决策信息 → 需要接近满仓时的警示态 |
| 死亡丢一半背包 | 结算/死亡面板必须清楚给出"损失/保留"两项 |
| 5/10/15 层是 Boss 层 | 需要**全屏宽度级**的 Boss 血条，但不能与顶部 HUD、提示条冲突 |
| 支持键鼠与触屏两套输入 | 触屏按钮需安全区适配；面板在手机上要降密度 |

## 平台与画面

- 目标平台：桌面浏览器 + 移动浏览器（触屏）
- 方向：横屏（竖屏不做适配，stage 用 `max-width:calc(100vh*16/9)` 保比例）
- 画面比例：16:9
- 内部分辨率：**1024 × 576**（Canvas 逻辑像素），TILE = 32
- DOM HUD 按 CSS 像素渲染并随 stage 缩放，**与 Canvas 存在缩放比差**（1280×720 窗口下约 1.2266×）
  → 结论：**HUD/面板一律用 DOM，只有游戏世界用 Canvas**

## 范围

- 本次范围内：HUD 信息层级、Boss 血条层级、提示条（toast）、地表标签可读性、设置面板、首次引导、设计 Token 统一
- 本次范围外：美术资源（本项目**零图片依赖**，所有图形程序化绘制）、引擎化、联网

## 验收标准（可验证）

**视觉**
- 所有 DOM 颜色经 `var(--*)` 引用，无新增裸色值
- Canvas 字体只用契约中的 4 档字号与 1 套字体栈
- 长文案不溢出容器：HUD 条内文本宽度 ≤ 容器宽 − 24px

**功能**
- Boss 血条与 toast **在任何窗口尺寸下不重叠**（几何断言）
- 设置面板可开合，音量/震动/减少动效/触屏按键 4 项改动即时生效且跨刷新保留
- 首次进入的引导只出现一次，可跳过，跳过状态持久化
- 地表建筑标签不被画布左右边缘裁切

**约束**
- 仍然是**单文件、零外部依赖、双击可玩**
- 控制台 0 错误 0 异常；既有 126 项 CDP 断言不得回归
