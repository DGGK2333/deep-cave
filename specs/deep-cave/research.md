## 2. 实测缺陷（按严重度）

### D1 · Boss 血条与 toast 重叠（严重，我自己上一轮引入的）
- Canvas 侧：`drawBossBar()` 画在 canvas y=78、宽 520、高 16+8
- DOM 侧：`#toast{top:96px}`，`.tst` 高约 30px
- 换算：1280×720 窗口下 stage 宽 1256 → 缩放 1.2266 → canvas y=78 ⇒ **CSS y ≈ 95.6px**
- 结论：**两者几何完全重叠**，截图里 toast 直接压住 Boss 名字与血量
- 根因：Canvas 与 DOM 混用同一片顶部区域，却没有共同的层级与安全区约定

### D2 · HUD 条形内文案过长被挤压
`#hudL` 宽 216px，绳索条文字为：
`第 15 层绳索 620 / 3000（剩余 280）` — 约 22 个字符 + 数字，11px 字号在 16px 高的条内**贴边**
且 `第 N 层` 与右侧 HUD 的 `第 N 层 · 泥土矿洞` **信息重复**。

### D3 · Canvas 字体有 6 套，且字体栈不一致
| 位置 | 当前写法 |
|---|---|
| Boss 血条 | `bold 12px sans-serif` ← **缺中文字体回退** |
| 建筑招牌 ×3 | `bold 11px "PingFang SC",sans-serif` |
| 掉落武器名 | `700 10px "PingFang SC",sans-serif` |
| 飘字 | `700 13px "PingFang SC","Microsoft YaHei",sans-serif` |
| 地点标签 | `600 13px "PingFang SC","Microsoft YaHei",sans-serif` |
| 提示药丸 | `600 13px "PingFang SC",sans-serif` |

→ 同一屏里 6 种字号/字重组合、2 套字体栈。Boss 血条那套在非 macOS 上会落到别的字体。

### D4 · 地表建筑标签被画布边缘裁切
`label()` 用 `ctx.textAlign='center'` 直接画在 `p.tx*TILE+16-cam.x`。
赌场在 tx=6，当 `cam.x` 夹紧到较大值（玩家在右侧）时，标签中心落到屏幕 x≈32，
「赌场 · 红与黑」左半截被画布左边缘切掉（截图已复现）。

### D5 · 缺少"设置 / 暂停"这一屏
Esc 打开的是 `openMenu()`：只有系统说明 + 返回/触屏按键/重新开始。
**没有**音量控制（只有 M 静音开关）、没有震动强度、没有减少动效、没有集中操作说明。
无障碍相关项（动效/震动）一个都没有 —— 这是 `game-ui-extension` 审计出的最大断点。

### D6 · 没有首次进入引导
`startMenu()` 用两块 `.item` 讲系统，但**进入游戏后没有任何第一步指引**。
玩家开局 0 金币 + 价值 100 的镐子，需要自己发现"碎石机可摇钱"或"商店能买武器"。

### D7 · 暗场景下 HUD 边界不清
`.hudbox` 是 `rgba(10,13,22,.72)` + `1px rgba(90,105,150,.35)` 描边。
在"深渊回廊/泥土矿洞"这类暗色主题里，HUD 与背景对比不足，盒子边界看不出来（截图可见）。

## 3. 参考抽象（不复刻任何作品）

- **层级**：暗底 + 单一金色强调（#f5c542）用于货币与关键数字 → 保留，扩展为语义 token
- **形状**：8/10/11/16px 四种圆角混用 → 收敛到 3 档
- **密度**：信息型面板（商店/工坊/赌场）密度偏高，但符合"决策一次看全"的需求 → 保留密度，改为**分组 + 分隔**
- **反馈**：已有 toast / 飘字 / 粒子 / 震屏四类 → 补"减少动效"开关
- **版权**：所有图形为程序化绘制，不引入任何第三方素材

## 4. 关键决策

1. **HUD 与面板一律 DOM，Canvas 只画世界**。Boss 血条从 Canvas 搬进 DOM（D1 根治，且文字更清晰）。
2. **Canvas 字体收敛为 1 套字体栈 + 4 档字号**，由 JS 常量 `UI` 提供（D3）。
3. **条形内只放数字**，语义与层级移到标签/图标（D2）。
4. **新增 `settings` 屏 + `tutorial-overlay` 屏**（D5 / D6），两者都做成可跳过的轻量层。
5. **不动美术与玩法**：本次是 UI 层重构，不改任何数值与判定。

## 5. 风险

| 风险 | 处理 |
|---|---|
| 单文件 142KB，改动面大 | 用带锚点断言的补丁脚本，任一处对不上就整体不写盘 |
| Canvas 字体改成常量后可能有漏改 | CDP 断言：扫描全部 `ctx.font=` 出现位置 |
| 设置项持久化污染存档 | 用独立的 localStorage key（`deepcave_ui`），不进存档 JSON |
| 手机上新增 DOM 层挤压触屏按钮 | 设置/引导为模态覆盖层，触屏按键 `z-index:15` 低于覆盖层 |
